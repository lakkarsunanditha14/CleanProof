# CleanProof: project brief (PS-D04 "Resolved, Allegedly", 24h hackathon)

Read this fully before changing anything. The app is finished and demo-ready.
Make only the change asked for, test it, and do not add features that were not requested.

## What it does
Citizens report civic issues (garbage dump, blocked drain, construction debris, unswept street)
with a photo + GPS. A worker closes a complaint with an after photo, and CleanProof verifies it:

| Check | Penalty |
|---|---|
| AI vision (CLIP, local): problem not reduced vs the citizen's before photo | -50 |
| Location: photo GPS > 50 m from complaint, or no GPS | -30 |
| Time: photo taken before complaint/reopen, or no timestamp | -30 |
| Duplicate: perceptual hash matches an earlier closure photo | -30 |
| Camera data: no EXIF | -10 |

Score starts at 100. >= 75 VERIFIED, 40-74 SUSPICIOUS, < 40 LIKELY FAKE.
Flagged closures go to human review (Confirmed fake reopens the complaint). Nothing is automatic.

Other features: live in-app camera (no gallery; server clock + device GPS; evidence stamp burned
into the saved photo with server time, ward, street only if GPS <= 30 m, distance), photo evidence
panel, blurry/dark photos rejected with a retake message, late closures require a delay reason,
citizen reopen, dashboard (map, hotspots, charts, ward table), Track search by ID/title/ward.

## Stack
- frontend/: React + Vite + Tailwind, react-leaflet, recharts. Pages in src/pages, shared UI in
  src/components (Verification.jsx = photo, reasons, PhotoEvidence; CameraCapture.jsx = live camera).
- backend/: FastAPI + SQLite (SQLAlchemy). app/services: verification.py (5 checks),
  clip_service.py (CLIP openai/clip-vit-base-patch32, category + general labels, 4 zoomed crops),
  image_quality.py (blur/dark gate), photo_stamp.py, exif_service.py, sla_service.py.
- Database: one file, resolved_allegedly.db at the project root (absolute path in config.py).
- No API keys. Everything runs offline except the map tiles.

## Run
- Double-click START_DEMO.bat (asks before resetting; N keeps data). App: https://localhost:5173
  (self-signed certificate: click Advanced > Continue). Use Edge (camera is blocked in the School
  Chrome profile).
- Or: `cd backend; .\venv\Scripts\python.exe -m uvicorn app.main:app --port 8000` and
  `cd frontend; npm run dev`.
- scripts/reset_demo.py DELETES all complaints and recreates the 6 demo ones. Only run it when the
  user asks. `--with-history` adds 194 synthetic past complaints.
